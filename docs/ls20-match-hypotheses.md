# ls20 match 可证伪假设（任务 B 探路）

> 2026-09-05 · 人提出、代码实测、证据裁决  
> 纪律：**不猜**。每条假设有明确支持/推翻条件；以线上实测为准。  
> 脚本：`tools/ls20_match_probe.py` → 报告：`docs/ls20-match-probe-report.md`

---

## 共同观测指标

| 指标 | 含义 |
|------|------|
| `levels_completed` | 是否过关 |
| 色0/1 像素数与 bbox | 目标标记是否变化/清除 |
| 色9 游戏区连通块（y&lt;54） | 槽/携带物 |
| 色12 bbox | 移动对象 |
| `changed_pixels` | 非位移副作用 |

**「过关效应」**：`levels_completed` 严格增加。  
**「标记清除效应」**：色0/1 像素数降为 0。  
**「match 过关」** 仅认过关效应；标记清除单独记账，不自动等同通关。

## 第一轮（H1–H4）— 已实测裁决

### H1 — 移到色0/1 近邻即过关/盖印

**陈述**：色12 到色0/1 最近 walkable 后出现过关或标记清除（仅 ACTION1–4）。  
**裁决：REFUTED**（到位 levels 不变；n01 未清零。到位后 n01 反常膨胀，见报告）。

### H2 — 移到游戏区色9 近邻即过关

**陈述**：到色9 连通块最近 walkable 后过关。  
**裁决：REFUTED**（自动选中的块是光标下方随动块，target=起点，path 空，无效应）。  
**附带认知**：该色9 块随光标移动 → 见 H6。

### H3 — 仅方向移动即可触发

**陈述**：无需 ACTION5/6。  
**裁决：REFUTED**（H1 到位无效应；同位置 ACTION5 后出现标记清除）。

### H4 — L1 到位即 levels+1

**裁决：REFUTED_OR_ANCHOR_WRONG**（H1/H2 均未 levels+1；ACTION5 后仍 levels=0）。

## 第二轮（H5–H7）— 由第一轮证据提出

### H5 — 在色0/1 近邻发 ACTION5 → 色0/1 清除

**陈述**：BFS 到色0/1 最近 walkable，再发 **一次** ACTION5，出现标记清除效应。  
**支持**：n01→0。  
**推翻**：ACTION5 后 n01 仍 &gt;0。  
**注意**：不要求 levels+1；若 levels 也 +1，额外记入 H7/通关线索。

### H6 — 「紧贴色12」的色9 块是携带物渲染，不是固定目标槽

**陈述**：任意至少 1 步移动后，该色9 块中心与色12 锚点的相对偏移保持稳定（|Δrel|≤2px 量级），且起点处的「脚下色9」离开原 bbox。  
**支持**：相对偏移稳定且原点 bbox 空出。  
**推翻**：移动后该块仍留在原 bbox，或相对偏移剧烈变化（&gt;10px）且不跟随。

### H7 — 排除随动色9 后，固定色9（如开局顶区块）近邻 + ACTION5 可过关

**陈述**：对「不与色12 相邻」的游戏区色9 块，走到其最近 walkable，发 ACTION5 → `levels_completed` +1。  
**支持**：levels 严格 +1。  
**推翻**：到位+ACTION5 后 levels 不变。

## 裁决规则（写 match 时）

1. 只实现 **SUPPORTED**。  
2. REFUTED / INCONCLUSIVE 不写进通关逻辑。  
3. 标记清除 ≠ 通关，除非同次观测到 levels+1。
