# 龙泉的会学方法论：从已知规则到未知规则

> 2026-09-05 · Longquan 龙泉 · 这是龙泉的方法论根基，不是待办，是宪法
> 题眼：**规则及其组合——前者量小可穷尽，后者量大易爆。**

---

## 0. 一句话题眼

ARC 游戏的规则，可以拆成两层：

- **规则原语（primitives）**：反射、旋转、平移、复制、颜色映射、缩放、对称…… 数量有限，可穷尽。
- **规则组合（composition）**：原语的排列组合，数量爆炸，无法穷举。

**会学的本质 = 抓住「可穷尽的原语层」，用「组合语法」去约束「会爆炸的组合层」。**

如果只想「穷举所有规则」，必死——组合空间大到你下辈子都搜不完。如果只想「背具体答案」，更死——那是罐头，不是会学。真正的出路，是**在两层之间架一座桥：用少量原语 + 一套组合规则，生成性地覆盖大量具体规则。**

---

## 1. 三层定位（我们卡在哪）

| 层 | 规则从哪来 | 程序做什么 | 状态 |
|----|-----------|-----------|------|
| L0 背题 | 人把答案写死 | 照抄 | ls20/ar25 罐头，已废弃为基线 |
| L1 已知规则+搜参数 | 人读源码，把规则写成假设空间 | 在规则空间搜参数 | **M1 做到的就是这层** |
| L2 未知规则+归纳 | 程序自己从观测归纳规则 | 先归纳规则，再搜参数 | **龙泉的真正目标，还没做** |

M1 的本质是 L1：我们读引擎源码、把「色10=轴、反射规则」写成 `hypotheses/mirror.py` 喂给程序。**人替程序完成了最关键的「规则归纳」一步**，程序只做了「给定规则下搜参数」。

L2 才是「未知规则求解」：程序拿到一个没读过源码的游戏，自己归纳出规则。这是龙泉的方向。

---

## 2. 从 L1 到 L2 的核心算法：把「搜索」往上升一层

L1 搜的是「参数的假设空间」（块该挪到哪）。
L2 搜的是「规则的假设空间」（规则是什么）。

两者结构相同，只是搜索对象升了一级：

```
L1:  固定规则 R → 搜参数 θ → 验证
L2:  搜规则 R → 搜参数 θ(R) → 验证 R 和 θ
```

L2 的三个支柱：

### 支柱一：感知原语库（跨游戏通用）

连通域、对称轴、平移、旋转、颜色映射、路径点、包围盒…… 这些是几乎所有 ARC 游戏都在用的原始结构。程序先从帧里提取这些**不带游戏知识的原始结构**——「这里有个 L 形连通域」「这里有条贯穿全场的线」「这个颜色出现 5 次」。

### 支柱二：规则模板库（从已知游戏归纳，可组合）

从已解游戏里归纳的不是「AR25 是反射」，而是**规则的原语形状**：

- 「对象关于某条线对称」→ 反射原语
- 「对象整体位移」→ 平移原语
- 「颜色按某映射变换」→ 颜色映射原语
- 「对象沿路径移动到目标」→ 路径点原语

这些是模板，不是具体规则。AR25 只是「反射原语」的一个实例。

### 支柱三：可证伪预测 + 主动实验

对每个规则假设，提一个可被环境打脸的预测：「如果规则是反射，我把块移到 (x,y)，应该看到镜像出现在 (x',y')」。然后真的去试，对了保留假设，错了淘汰、换下一个原语。

---

## 3. 少量游戏凭什么能覆盖未知游戏？（归纳偏置，不是逻辑保证）

**诚实的前提：没有任何东西能在逻辑上保证归纳正确。** 「没有免费的午餐定理」说得清楚——不存在在所有可能世界都强的策略。

但 ARC 可行的底气，来自三个「在这个世界里大概率对」的归纳偏置：

1. **奥卡姆剃刀**：规则是「人设计的、简洁的」。所以「最短的规则描述」最可能是真规则。搜规则时优先搜简单的。

2. **视觉结构先验**：对象、对称、颜色、连接——这些概念在几乎所有 ARC 游戏成立。感知原语和规则模板的复用，是这个世界的属性，不是我们的技巧。

3. **组合语法**：ARC 规则是少数基本原语的组合。所以「原语库」是有限的、能覆盖大部分情况的。

**这三条合起来 = 一个赌注：ARC 的规则空间 = 人类视觉原语的组合空间。** 这个赌注没有数学证明，但有强前验——因为 ARC 的设计目标就是测这个。如果规则超出人类视觉原语，那它不再是智力测试，而是无规律噪声。

## 4. 外部公开资料能汲取吗？——能，而且是正路

ARC 有天然宝藏：大量开源高分解法、人类解题轨迹、社区 Notebook、学术论文。

三种汲取：

1. **人类轨迹** → 反推「人用了哪些视觉原语」，是「原语清单」的最直接来源。
2. **开源求解器** → 高分队伍代码里藏着「他们归纳出的规则模板」，是「原语怎么组织成可搜结构」的参考。
3. **学术论文/报告** → Chollet 的 ARC 论文明确讨论过「ARC 需要哪些核心能力」，是「原语理论」的权威来源。

**汲取纪律（不可破）**：汲取「原语的抽象」，不是「具体游戏的答案」。把 tycho 的解搬过来是背题；看懂「tycho 用了对象复制 + 对称」这个抽象、变成你的原语之一，是合法的学习。

这正是灵境里那套「先验卡片 + 思想/模块/不可搬分类」的价值——它就是为了这一刻准备的。

## 5. 这条方法论对龙泉的落地含义

1. **hypotheses/ 目录的定位**：它不是「每个游戏一个特解文件」，而是「每个原语一个模块」。mirror.py 不该叫 mirror，该叫 `reflect.py`（反射原语）。未来会有 `translate.py`、`recolor.py`、`copy.py`……每个是一个原语。

2. **search.py 之上要加一层「原语选择器」**：面对新游戏，程序先判断「用哪个原语（或哪几个原语的组合）」，再进 search。这一层就是 L2 的入口。

3. **ft09 的意义**：它不是「多解一个游戏」，是「逼我们把 L1 升到 L2」——ft09 没读过源码、没写过假设空间，程序必须自己归纳规则，否则就废。这就是路线规划里「B 优先」的方法论必然性。

---

## 6. 一句话总结

**规则原语量小可穷尽，规则组合量大易爆——会学就是在可穷尽的原语层上，用组合语法去生成性地覆盖会爆炸的组合层。** 这是龙泉区别于「背题」和「穷举」的唯一正路。

外部公开资料（人类轨迹、开源求解器、论文）是「原语清单」的正规来源，但汲取的是抽象，不是答案。
