## 本轮假设（可证伪）

### H10 — 色5 块为盖印槽（优先）

- **H10a**：对 RESET 时 playfield 色5 主块（起始形状）近邻 + ACTION5 → `levels+1`。  
  - 支持：levels 0→1。推翻：levels 仍 0。  
  - 注：与 H7 目标区高度重叠；若失败，强化「顶区色5/9 ≠ 过关槽」。
- **H10b**：先做 H5（清色0/1），再在**新帧**上重扫色5/色5+9 窗口；若出现新槽候选，逐个近邻 + ACTION5。  
  - 支持：某候选触发 levels+1。  
  - 推翻：清标记后无新槽，或所有新/旧候选 + ACTION5 仍 levels=0。  
  - 若清标记后无任何新色5 槽 → H10b 记 **REFUTED（槽未出现）**。

### H8 — 固定色9 块清除触发过关

对每个**非携带** playfield 色9 块：近邻 + ACTION5。  
- 支持：某块像素清零且 levels+1。  
- 推翻：所有固定色9 都试过，无一带来 levels+1（块是否清除分开记账）。

### H12 — 全部标记清除后才 levels+1

序列：H5 清色0/1 → 再清所有固定色9（各近邻+ACTION5）→ 看最终 levels。  
- 支持：最后一次清除后 levels+1。  
- 推翻：全部可清标记处理后 levels 仍 0。

### H9 — 多色9 顺序（本轮降级）

全排列 120 超出本轮预算。仅当 H8/H12 出现「多块可清但未过关」时，再开候选顺序子集。本轮默认 **DEFERRED**。

### H11 — 携带状态是钥匙（本轮可证伪边界）

记录每次 ACTION5 前的 `carrying`。若始终同一 carrying 且从未 levels+1 → **INCONCLUSIVE**（无法变换携带，不能推翻「携带不对」）。  
仅当找到第二种 carrying 且仅其一能 levels+1 → SUPPORTED。
