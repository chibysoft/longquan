### 决定性新发现（离线已证）

1. **(10,10) 是 L3 唯一 ov≥10 格**——穷举所有 cell，只有 (10,10) 与 stamp 重叠 ≥10px。**不存在旁门盖印位**，mover 必须进 (10,10) 才能过关。
2. **(10,10) 只有两个可走邻居**：(10,9)[上] 与 (10,11)[下]；左右 (9,10)/(11,10) 足迹含 color4 墙，`walk_u=False walk_a=False`。
3. **(10,11)[下] 不可达**——它是孤立口袋（左右墙封死），从起点 walk_u BFS **无法到达**。所以 mover **只能从上方经垂直传送门进入 (10,10)**。方向说被排除。
4. **L1/L2/L3 stamp 格结构几乎全同**（color5 内嵌 2~3px color9 字形），而 L1(无仪式)/L2(UDD) 都**进得了自己的 color9 字形格并过关** → "color9 是硬墙"不是答案，**L3 的封锁是 L3 特有**。
5. **字形是干净的变换族**：
   - L1 = A `###/..#/#.#`（无仪式）
   - L2 = B `###/#../#.#` = fx(A)（仪式 UDD）
   - L3 = C `#.#/#../###` = rot180(A)（仪式 ?）

## 判读

封锁只可能来自两个 L3 特有因素（二选一，都可测）：

- **H-字形族**：C=rot180 需要不同于 UDD（=fx）的仪式 → 在接触点扫一套 rot180 候选仪式。
- **H-环压**：环（L3 独有 color14）压碎触发 legend flip（E7 已证是真实状态变化），是武装步骤 → 用户 E8 直觉。**E10 因燃料混淆（压碎后 fuel=1）未测净**。
