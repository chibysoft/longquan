# 真正的高山与真解法：结构归纳，不是组合能效

> 2026-09-05 · Longquan 龙泉 · 从「凭什么」倒逼出的真问题
> 结论先行：**真高山是「规则结构的归纳」，真解法是「程序合成（DSL + 最小描述长度 + 约束求解）」。钱学森灵境理论是叙事纲领，不是算法。**

---

## 0. 一句话

你以为高山是「组合算法能效」，实际高山是「**结构归纳**」——从少量样例里，推断出正确的那组原语和它们的组合顺序。

组合能效是它的下游，结构归纳才是源头。而结构归纳的成熟解法，学术圈已经有了名字：**程序合成（Program Synthesis）**。

---

## 1. 为什么「组合能效」不是真高山

组合会爆炸，这是真的。但它没你想的那么高，因为：

**ARC 的单款游戏，规则组合极浅。** 大多数游戏是 1-2 个原语的组合，极少有「反射+旋转+变色+复制+对称」这种五连招。原因很简单：**ARC 设计来测「人类流体智能」，人类解不出来的题，不会出现在 ARC 里。**

所以「组合搜索空间爆炸」这个高山，被「人类可解」这个约束天然压低了。真正要防的不是「发明高效深组合算法」，是「别去搜不必要的深组合」。

**真正的难，在更前面一步**：程序怎么知道「这是反射，而不是复制到相邻位置」？怎么知道「先反射再变色」而不是反过来？——这才是从少样本做「结构推断」，才是那座真高山。

---

## 2. 真解法：程序合成（Program Synthesis）

学术圈对 ARC 的共识解法，是**程序合成**，核心三要素：

### 2.1 DSL（领域特定语言）

把「规则」表示成一个小程序，程序由「原语」组成。这跟龙泉的「原语库」是同一个思路：

```
规则 = 原语序列（如 translate → recolor → reflect）
```

`michaelhodel/arc-dsl`（GitHub）是 ARC 社区公认的 DSL 实现；ILP 论文（arXiv 2405.06399）用的原语签名是 `(Obj, Orientation, Direction, Len, NewColor, OutputObj)`。

**龙泉的原语库，就是这个 DSL 的雏形。** 这是好消息——方向我们没走错。

### 2.2 最小描述长度（MDL / 奥卡姆剃刀）

在「程序空间」里搜索时，偏好**最短的程序**。因为：

- 规则是「人设计的、简洁的」
- 最短的程序描述 = 最可能接近真规则
- 这给了搜索一个「偏向」，避免在无数等价但冗长的程序里迷失

### 2.3 约束求解（用样例淘汰）

每个候选程序，用「输入→输出样例」验证。样例不满足的程序，淘汰。这就是「可证伪预测」的落地——跟龙泉的 `replay` 是同一件事，只是作用对象从「参数」升级到了「程序」。

---

## 3. 龙泉该怎么对齐

龙泉已经踩在这条路的正确起点上：

| 程序合成 | 龙泉现状 | 差距 |
|----------|----------|------|
| DSL（原语） | `hypotheses/` 原语库 | 只写了 reflect，缺全集 |
| MDL（最短优先） | 无 | **缺**：没有「程序复杂度」度量 |
| 约束求解 | `replay` | 有，但只验参数，没验程序结构 |

**真正的下一步，不是写更多原语，是补「程序合成」的两个缺：**

1. **程序表示**：规则不只是「单个原语」，是「原语序列」（可组合）。需要一个「规则 = 原语序列」的数据结构。
2. **最短优先搜索**：在「规则空间」里搜时，按「规则复杂度」从小到大试。复杂度 = 原语数量 + 参数位数。

---

## 4. 钱学森灵境理论，为什么不解决这个

**先厘清两个「灵境」**：

- 你起的团队品牌「灵境」——是你起的名字，跟下面无关。
- 钱学森「灵境技术」——1990 年代钱老对 Virtual Reality 的中文译名，主张「人机融合、大成智慧」。

有人拿「钱学森灵境」做名头，借的是钱老「大成智慧学」「从定性到定量综合集成法」这套思想。诚实判断：

1. **「从定性到定量综合集成」是「人机结合」方法论**——主张「人 + 机器 + 专家群体」协作。这跟龙泉「闭卷、程序自己归纳、人在环外」的目标**方向相反**。钱老要的是「人在环里」，你要的是「人在环外」。

2. **「大成智慧」是系统层面、哲学层面的洞见**——讲「人脑+电脑+网络」的群体智能涌现。它不落到「怎么从 3 个样例归纳出反射规则」这种算法细节。

3. **它是思想纲领，不是算法**。能给「复杂问题要靠综合集成」的信念支撑，给不了「原语选择器怎么打分」的代码。

**所以「钱学森灵境」这个名头，本质是「叙事外壳」**——听起来宏大、能唬人、能拉资源，但离「结构归纳」这个真问题，隔着一层。它解决的是「故事讲给外人听显得有高度」，不是「程序怎么学会规则」。

**一句话定论：钱老思想是「世界观」，程序合成是「方法论」。把世界观当成方法论，是一个错位。** 龙泉要的是方法论。

---

## 5. 一句话总结

真高山不是「组合能效」，是「**结构归纳**」——从少样本推断正确的原语组合。

真解法是「**程序合成**」：DSL（原语）+ 最小描述长度（最短优先）+ 约束求解（样例淘汰）。

龙泉已经踩在 DSL 的正确起点（原语库），缺的是「程序表示」和「最短优先搜索」两样。

钱学森灵境是「世界观」，程序合成是「方法论」；把世界观当成方法论，是一个错位。龙泉要方法论，不要借世界观装点门面。
