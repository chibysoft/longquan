- 左踩 (14,50) 时上方色6 挡住 A1 → 右独爬桥

### 已跑通的子程序

1. 左踩底板块 → 右 A1 独爬至中层/顶层  
2. 右踩 (58,26) 打开左 c12 门（左常被外推到 x=2）  
3. 顶缝失同步：可到同 x 不同 y，如 (26,6)/(26,50)  
4. **通关**：黄金 `(10,42)+(58,26)` → A1 穿门 → 顶水平贴合 → **A3** 压缩过关

### 离线消融

打开中缝 6\|7 → `find_mate_path` 有解 → 过关仍是 **贴合+压缩** 族。  
垫可踩 + HOLD 板模型的状态机 BFS 可搜到黄金态（path 例 `[3,3,3,1,1,1,1,3,1,4,4,1,4,4]`，live A3=内收）。
